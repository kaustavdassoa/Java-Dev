## Java Streams Fundamentals

Java streams provide a functional approach to processing collections of data. They allow you to express complex data processing operations clearly and concisely.

### Key Concepts

1. **Stream Creation**: A stream is a sequence of elements that can be processed in parallel or sequentially.
2. **Intermediate Operations**: These operations transform a stream into another stream (e.g., filter, map).
3. **Terminal Operations**: These operations produce a result or side-effect (e.g., collect, forEach).
4. **Pipelining**: Multiple operations can be chained together.
